# Undangan Pernikahan Ilham & Dinda

Website undangan digital satu halaman untuk GitHub Pages.

## Isi repository

- `index.html` — halaman undangan digital.
- Seluruh gambar dan musik sudah tertanam di dalam HTML, jadi tidak perlu mengunggah folder aset terpisah.

## Cara mengunggah ke GitHub

1. Buat repository baru di GitHub, misalnya `undangan-ilham-dinda`.
2. Atur repository menjadi **Public** jika menggunakan GitHub Pages gratis.
3. Unggah file `index.html` ini ke bagian paling atas/root repository (bukan di dalam folder lain).
4. Klik **Settings** pada repository.
5. Buka **Pages** pada menu sebelah kiri.
6. Pada bagian **Build and deployment**, pilih:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
7. Klik **Save** dan tunggu proses deployment selesai.
8. Buka alamat GitHub Pages yang ditampilkan di halaman Settings → Pages.
